# Skill catalog

| Skill | Capability |
|---|---|
| `requirements-engineering` | Turn an Android product idea or changed behavior into testable requirements. |
| `feature-planning` | Plan a feature, defect repair or scoped Android change with dependencies and verification. |
| `android-project-bootstrap` | Create a new Kotlin/Compose app and establish a reproducible build baseline. |
| `android-clean-architecture` | Define or repair Android layer boundaries, module dependency direction and ADRs. |
| `dependency-injection` | Design dependency lifetimes and integrate Hilt or the project’s existing DI. |
| `material3-design-system` | Specify or implement consistent Material 3 colors, typography, shapes and component states. |
| `compose-ui-patterns` | Implement Compose screens, reusable components and explicit loading/empty/content/error rendering. |
| `adaptive-ui-accessibility` | Adapt Android UI for window size, assistive technology, font scaling, localization and RTL. |
| `kotlin-best-practices` | Implement maintainable Kotlin logic with safe concurrency, nullability and error handling. |
| `state-management` | Design lifecycle-aware StateFlow state and unidirectional Android event handling. |
| `navigation-deeplinks` | Implement navigation graphs, safe arguments, back behavior and Android app links. |
| `api-integration` | Implement Retrofit/OkHttp integrations from an OpenAPI or documented REST contract. |
| `local-persistence` | Implement Room/DataStore storage with tested migrations and explicit data retention. |
| `offline-first-sync` | Design local-first reads, durable writes and conflict-safe background synchronization. |
| `android-security` | Review Android threat boundaries, permissions, secrets, dependencies and release security. |
| `unit-testing` | Write and run deterministic JVM tests for domain, ViewModel and repository behavior. |
| `compose-ui-testing` | Test Compose semantics, state rendering, interaction and accessibility behavior. |
| `integration-e2e-testing` | Validate Android data integration, migrations and critical user journeys end to end. |
| `android-static-analysis` | Configure and execute Android Lint and appropriate Kotlin static analysis. |
| `performance-optimization` | Measure and improve startup, Compose, database, memory, network or battery performance. |
| `gradle-build-management` | Manage Gradle variants, wrapper integrity, dependency catalogs and release artifacts. |
| `android-ci-cd` | Create Android CI for reproducible builds, tests, lint and reviewed release preparation. |
| `play-store-publishing` | Prepare or submit an approved Android App Bundle to a specific Google Play track. |
| `crash-monitoring-maintenance` | Instrument, investigate and maintain post-release Android health with privacy-aware monitoring. |
