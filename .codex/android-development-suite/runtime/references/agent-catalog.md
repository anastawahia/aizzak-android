# Agent catalog

| Agent | Mission |
|---|---|
| `android-orchestrator` | Own Android tasks through specialist routing, accepted handoffs and human requirements, design and PR checkpoints. |
| `product-analyst` | Convert product intent into prioritized, testable Android requirements. |
| `android-architect` | Define maintainable Android boundaries and migration decisions. |
| `ui-ux-designer` | Produce implementable Material 3 Android screen and journey specifications. |
| `compose-developer` | Implement accessible, adaptive Compose screens and components. |
| `android-core-developer` | Implement Kotlin domain/application behavior and lifecycle-aware ViewModels. |
| `integration-engineer` | Implement secure API, persistence and offline synchronization boundaries. |
| `android-qa-engineer` | Design and execute Android verification tied to acceptance criteria. |
| `security-reviewer` | Independently review Android trust boundaries, credentials and release security. |
| `performance-engineer` | Measure and address Android startup, memory, ANR, battery and rendering bottlenecks. |
| `build-release-engineer` | Own reproducible Android builds, signing, CI and approved release submission. |
| `android-code-reviewer` | Independently review correctness, maintainability and Android implementation quality. |
