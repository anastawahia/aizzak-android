# Role catalog

| Department | Role | Mission |
|---|---|---|
| Management | `company-director` | Run the Android software house for the owner: one contact from idea to Google Play, enforcing the lifecycle, gates and human checkpoints. |
| Product | `product-manager` | Turn the owner's idea into a product brief with a clear problem, users, MVP scope, risks and decisions the owner must make. |
| Product | `business-analyst` | Convert the approved brief into prioritized, testable requirements with stable IDs and traceability. |
| Design | `ux-designer` | Design journeys, information architecture, navigation and wireframes for every screen and state. |
| Design | `ui-designer` | Produce the visual design reference, design tokens and the machine-checkable screen inventory that the owner approves. |
| Design | `design-qa-reviewer` | Independently verify that the built screens match the approved design, element by element, from real screenshots. |
| Engineering | `android-architect` | Define maintainable Android boundaries, navigation structure and migration decisions. |
| Engineering | `android-core-developer` | Implement Kotlin domain and application behavior and lifecycle-aware ViewModels. |
| Engineering | `compose-developer` | Build Compose screens that reproduce the approved design reference and inventory, with accessible, adaptive behavior. |
| Engineering | `integration-engineer` | Implement secure API, persistence and offline synchronization boundaries against confirmed contracts. |
| Engineering | `backend-liaison` | Represent the Android team to backend owners through written, verifiable change requests, without editing the backend. |
| Quality | `qa-engineer` | Design and execute Android verification tied to acceptance criteria and the device/configuration matrix. |
| Quality | `android-code-reviewer` | Independently review correctness, maintainability and Android implementation quality. |
| Quality | `security-reviewer` | Independently review Android trust boundaries, credentials, privacy and release security. |
| Quality | `performance-engineer` | Measure and address Android startup, memory, ANR, battery and rendering bottlenecks. |
| Release | `build-release-engineer` | Own the project scaffold, reproducible builds, CI, signing and approved release submission. |
| Release | `store-listing-specialist` | Prepare an accurate, compliant and discoverable Google Play presence for the accepted app. |
| Operations | `app-operations-engineer` | Keep the published app healthy: monitoring, incident response and maintenance releases. |
