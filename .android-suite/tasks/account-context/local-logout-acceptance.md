# قبول رحلة الحساب الفعلية — الخروج المحلي

التاريخ: 2026-10-31، Asia/Baghdad.

بعد تثبيت APK النهائي وتشغيله وربط USB، طُلب من المستخدم تسجيل الدخول بحساب موثق ثم الخروج والدخول مجدداً دون إرسال أسرار. أكد المستخدم صراحة: «وصلت للرئيسية ونجحت إعادة الدخول».

هذه نتيجة تحقق بشري للرحلة الفعلية على الهاتف، منفصلة عن 55 اختبار JVM و15 اختبار واجهة معزولاً. لم يدخل المنسق بيانات الحساب أو يقرأ رموزه أو يخزن استجابة سياق شخصية. لا ادعاء بقياس زمن الرحلة أو اختبار جميع الأجهزة أو البيئة الإنتاجية.

التنفيذ المقبول محلياً: Android يحمّل context قبل الرئيسية، والخروج يمسح جلسة Firebase والسياق محلياً دون استدعاء `/me/logout` ذي الحظر الشامل في الباك إند العامل. احتُفظ بمحول HTTP دون مستدعٍ فعّال. لا تعديلات على الباك إند في هذه المتابعة؛ أي تغيير لاحق يذهب بطلب Markdown لمطوره وفق AGENTS.md.
