# استقبال مهمة تصميم Data Search Agent

- التاريخ: 2026-11-06
- المسار: `ui-redesign`
- النطاق المصرح: تصميم شاشات وكيل Data Search فقط، من دون تعديل مصدر التطبيق أو الباك إند.
- خط الأساس: تطبيق Android قائم بـKotlin وJetpack Compose، مع نظام تصميم AIZZAK وشاشة رئيسة تعرض Data Search كوكيل مؤجل.
- العقود الحاكمة: `AGENTS.md` و`docs/V1-AGREED-SCOPE.md` و`docs/UI-DESIGN.md`.
- المتطلبات المتتبعة: `V1-HOME-01..05`، `V1-LOCALE-01`، `V1-THEME-01`، `V1-QUALITY-01..02`، وقرار اعتماد إضافة النصوص والملفات إلى Data Search.
- حدود مؤكدة: لا تُفترض صيغ ملفات أو حدود أحجام أو مخطط API أو `space_id` أو شكل نتائج نهائي. أي عنصر يعتمد عليها يُوسم كقرار مطلوب قبل التنفيذ.
- ملكية الملفات: مخرجات هذه المهمة فقط تحت `.android-suite/tasks/data-search-agent/`.
- حالة Git عند الاستقبال: توجد تغييرات سابقة غير مرتبطة في Home والتنقل والموارد والاختبارات؛ تُحفظ ولا تُعدّل ضمن هذه المهمة.
- الباك إند: مملوك لفريق آخر بموجب `AGENTS.md`؛ لا تعديل ولا نشر ولا اعتماد على عقد غير مؤكد.

## المخرج المطلوب عند نقطة التصميم

رحلات مستخدم، مخططات هيكلية، مرجع بصري قابل للمراجعة، رموز تصميم، و`screen-inventory.json` صالح للتحقق، مع حزمة اعتماد عربية. يتوقف العمل قبل التنفيذ إلى أن يعتمد المالك التصميم.
