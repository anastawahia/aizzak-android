# رموز تصميم Data Search — وكيل RAG محادثي

الحالة: مرشح اعتماد مصحح لمرحلة `design`
التاريخ: 2026-11-06  
النطاق: `DS-REQ-01..15` و`SCR-DS-001..010`

## 1. المبدأ البصري

المحادثة هي سطح العمل الرئيس. يحتل سجل الرسائل والمؤلف المساحة الأهم، بينما تظهر المحادثات والمصادر ونطاق الاسترجاع كأجزاء مساندة لا تنافس الجواب. يحافظ المرجع على أدوار AIZZAK في `docs/design/UI-PREVIEW.html`: الأزرق للإجراء والتنقل والتركيز، والسماوي لهوية Data Search وجاهزية المصدر، والعنبر للعمل الجاري أو الانتباه، والخطأ للحذف والفشل.

لا تُفعّل Dynamic Color في هذا المرجع. كل حالة تحمل نصاً وأيقونة أو شكلاً؛ لا يعتمد المعنى على اللون وحده.

## 4. المسافات والأشكال

- شبكة: 4، 8، 12، 16، 20، 24، 32dp.
- هامش compact للمحادثة: 12–16dp لتوسيع السجل؛ الشاشات الإدارية: 20dp.
- فجوة رسائل: 12dp؛ padding الفقاعة: 12×14dp؛ أقصى عرض فقاعة المستخدم 84%.
- shapes: 12dp للحقول والأزرار، 16dp للرسائل والبطاقات، 20dp للحوارات، وحبة كاملة للشرائح.
- المؤلف أدنى 56dp ويتمدد حتى 6 أسطر ثم يمرر داخلياً؛ زر الإرسال 48×48dp على الأقل.
- لا ظلال ثقيلة أو gradients. الحدود 1dp، والتركيز حلقة `primary` بعرض 3dp.

## 5. المكونات والحالات

### شريط المحادثة

- رجوع اتجاهي، عنوان المحادثة، اسم المساحة، وزرا المحادثات والمصادر.
- شريحة النطاق تقول صراحة «كل المصادر المفهرسة» أو «N مصادر محددة».
- منتقي النموذج لا يظهر إلا إن أكد العقد الكتالوج ومسار التثبيت.

### سجل الرسائل

- رسالة المستخدم في `primaryContainer` بمحاذاة end؛ رسالة المساعد على `surface` مع حافة/أيقونة `secondary` بمحاذاة start.
- الوقت والحالة نصان لا لون فقط. رسالة جارٍ إرسالها تعرض indicator مسمى.
- البث يظهر رسالة مساعد واحدة تتوسع تدريجياً مع شريط حالة «جارٍ توليد الإجابة»؛ لا ومض أو إنشاء فقاعة لكل جزء.
- الانقطاع يبقي النص الجزئي داخل `errorContainer` بوسم «رد غير مكتمل» وإجراء مصالحة/إعادة محاولة يدوي.
- Markdown والكود والروابط والنسخ ضمن الرسالة. مراجع المصادر تظهر كشرائح أسفل رسالة المساعد **فقط** إذا أعاد العقد مراجع منظمة؛ لا score ولا استشهاد مخترع.

### المؤلف

- label دلالي ثابت أو semantics واضح، placeholder مساعد، زر إرسال منفصل، وحالة تعطيل مع تفسير قريب.
- المسودة معزولة حسب الحساب والمحادثة. عودة الاتصال لا ترسلها تلقائياً.
- يبقى المؤلف فوق IME، ولا يغطي آخر رسالة؛ يوجد live region مقتصد لحالات waiting/streaming/complete/error.

### المحادثات

- compact: modal navigation drawer. expanded: start pane بعرض 260–300dp.
- الصف المحدد يستخدم `primaryContainer` مع علامة نصية/شكلية. الأفعال الأيقونية لها أسماء مترجمة وأهداف 48dp.
- الحذف يذكر أن سجل المحادثة وحده يحذف وأن ملفات المساحة لا تتأثر.

### المصادر ونطاق الاسترجاع

- compact: شاشة مصادر مستقلة وbottom sheet للنطاق. expanded: end pane بعرض 300–340dp.
- بلا تثبيت يعني كل المصادر المفهرسة في المساحة. أول تثبيت يضيّق النطاق إلى الملفات المثبتة؛ «استخدام الكل» يزيل التثبيتات ولا يحذف الملفات.
- كل مصدر يفصل سلامة الملف (`uploaded/scanning/ready/quarantined`) عن الفهرسة (`not started/pending/indexing/indexed/failed`). غير المفهرس لا يدخل نطاق الجواب.
- الرفع/الفهرسة مراحل مكتوبة، لا نسبة مخترعة. إضافة النص تبقى مشروطة بتأكيد `text/plain` والحدود.

### الإجراءات

- Primary: إرسال، إنشاء محادثة، إضافة مصدر صالح.
- Secondary/outlined: إلغاء، فتح أدوات، Done.
- Text: تحميل الأقدم، استخدام الكل، عرض التفاصيل.
- Danger: حذف محادثة أو مصدر، مع Cancel أول تركيز.
- Disabled: `surfaceVariant/onSurfaceVariant` مع شرح نصي؛ Pressed يخفض الإضاءة فقط؛ reduced motion يوقف الانتقالات غير الضرورية.

## 6. التكيف

| العرض | السلوك |
|---|---|
| `<600dp` | جزء واحد: المحادثة شاشة كاملة؛ المحادثات drawer؛ المصادر شاشة؛ النطاق bottom sheet. |
| `600–839dp` | rail عام + محادثة؛ جزء مساند واحد يفتح عند الطلب إذا سمح العرض. |
| `>=840dp` | ثلاثة أجزاء: محادثات start، المحادثة الأوسع وسطاً، المصادر end. |
| `fontScale >=1.3` أو ارتفاع ضيق | انهيار الأجزاء المساندة إلى drawer/sheet؛ المؤلف والأزرار يلتفون ولا يقتطع النص. |

لا تتعايش بيانات مساحتين في أي تكوين. تبديل المساحة يفرغ الأجزاء قبل الجلب.

## 7. الوصول والتدويل

- ترتيب القراءة: app bar، حالة النطاق، السجل من الأقدم إلى الأحدث، حالة البث، المؤلف، ثم الأدوات المساندة.
- السجل collection semantics، وكل رسالة وحدة واحدة باسم الدور والوقت. لا يعلن TalkBack كل token؛ يعلن بدء البث ونهايته أو انقطاعه.
- الأيقونات الزخرفية بلا وصف، وكل زر أيقوني له label مترجم. جميع الأهداف 48dp.
- RTL يعكس start/end والرجوع وترتيب الأجزاء، ولا يعكس النصوص LTR داخل الكود/اسم الملف.
- الخطأ يحتوي عنواناً ونصاً وإجراء. التركيز يعود إلى المصدر بعد إغلاق drawer/sheet/dialog.
- المرجع يغطي en/ar، light/dark، compact/expanded، وfont scale 1.3؛ لا يدعي ذلك اختبار TalkBack أو جهازاً فعلياً.

## 8. حدود العقد قبل التنفيذ

المرجع يثبت نموذج المنتج فقط. قبل التنفيذ يلزم تأكيد `master` لمفتاح Data Search، إتاحة المحادثات والرسائل والبث، شكل المحتوى والمراجع، ترقيم السجل، كتالوج/تثبيت النموذج، تثبيت ملفات المحادثة، صلاحيات الملفات والمعرفة، MIME/الأحجام و`text/plain`، واستعادة الرفع والمسودات/offline. لا يُستدعى بحث top-k منفصل من رحلة المحادثة لمجرد وجود endpoint للمعرفة.
