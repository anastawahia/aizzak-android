# استقبال مهمة تصميم Data Search Agent

- التاريخ: 2026-11-06
- المسار: `ui-redesign`
- النطاق المصرح: تصميم شاشات وكيل Data Search فقط، من دون تعديل مصدر التطبيق أو الباك إند.
- خط الأساس: تطبيق Android قائم بـKotlin وJetpack Compose، مع نظام تصميم AIZZAK وشاشة رئيسة تعرض Data Search كوكيل مؤجل.
- العقود الحاكمة: `AGENTS.md` و`docs/product/V1-AGREED-SCOPE.md` و`docs/design/UI-DESIGN.md`.
- المتطلبات المتتبعة: `V1-HOME-01..05`، `V1-LOCALE-01`، `V1-THEME-01`، `V1-QUALITY-01..02`، وقرار اعتماد إضافة النصوص والملفات إلى Data Search.
- حدود مؤكدة: لا تُفترض صيغ ملفات أو حدود أحجام أو مخطط API أو `space_id` أو شكل نتائج نهائي. أي عنصر يعتمد عليها يُوسم كقرار مطلوب قبل التنفيذ.
- ملكية الملفات: مخرجات هذه المهمة فقط تحت `docs/delivery/tasks/data-search-agent/`.
- حالة Git عند الاستقبال: توجد تغييرات سابقة غير مرتبطة في Home والتنقل والموارد والاختبارات؛ تُحفظ ولا تُعدّل ضمن هذه المهمة.
- الباك إند: مملوك لفريق آخر بموجب `AGENTS.md`؛ لا تعديل ولا نشر ولا اعتماد على عقد غير مؤكد.

## تصحيح المالك في 2026-11-06

- Data Search هو وكيل **RAG محادثي**؛ الشاشة الرئيسة سجل محادثة ومؤلف رسالة، وليست واجهة بحث عن ملفات أو قائمة نتائج `top-k`.
- تطبيق الويب في `\\wsl.localhost\Ubuntu-24.04\home\web_app` مرجع قراءة لاستنباط مبدأ العمل فقط: المساحة تملك محادثاتها وملفاتها، والمحادثة تسترجع افتراضياً من كامل مصادر المساحة المفهرسة أو من مجموعة أضيق من الملفات المثبتة.
- الملفات والفهرسة ونطاق الاسترجاع وظائف مساندة للمحادثة. لا تظهر مقتطفات البحث المستقلة على أنها المنتج النهائي، ولا تُعرض استشهادات إلا إذا أعادها عقد الرسالة بصورة منظمة مؤكدة.
- لا يغيّر التصحيح قرار تأجيل إنشاء/إعادة تسمية/حذف المساحات في Android؛ يختار المستخدم مساحة موجودة فقط.
- أعيدت مرحلة `design` إلى `changes_requested`، ويجب اعتماد الحزمة المصححة قبل أي تنفيذ.

## المخرج المطلوب عند نقطة التصميم

رحلات مستخدم، مخططات هيكلية، مرجع بصري قابل للمراجعة، رموز تصميم، و`screen-inventory.json` صالح للتحقق، مع حزمة اعتماد عربية. يتوقف العمل قبل التنفيذ إلى أن يعتمد المالك التصميم.
