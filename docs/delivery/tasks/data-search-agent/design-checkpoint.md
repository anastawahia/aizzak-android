## ما تغير في توحيد النظام البصري

1. توحد Chrome المراجعة مع `UI-PREVIEW.html`: خلفية الصفحة، حاوية المسودة، قياسات الغلاف، حدود عناصر التحكم والجهاز والملاحظة، وظل الجهاز.
2. أصبحت وجهة Data Search النشطة في rail تستخدم `primary/onPrimary` وفق عقد التنقل العام، بدلاً من `primaryContainer/onPrimaryContainer`.
3. عاد eyebrow والتحميل وشريحة اختيار المساحة إلى الأزرق الدلالي العام.
4. اقتصر السماوي على أيقونات هوية Data Search، الحافة الجانبية للمقتطف، وحالات المصدر `ready/indexed` المقرونة بالنص.
5. لم تتغير الرحلات أو النصوص أو عناصر الشاشات أو عقد API؛ بقي `screen-inventory.json` دون تعديل.

## ما تغير بعد مراجعة API

1. أصبحت المساحة سياقاً إلزامياً ظاهراً، وأضيفت شاشة اختيار مساحة موجودة وحالة no-space؛ لا إنشاء أو إدارة مساحات.
2. فُصلت رحلة الملف إلى تسجيل ورفع وإكمال وفحص أمان، بحالات `uploaded/scanning/ready/quarantined`.
3. فُصلت الفهرسة إلى `pending/indexing/indexed/failed`، ولا يصبح المصدر قابلاً للبحث لمجرد أن الملف `ready`.
4. «إضافة نص» أصبحت اقتراح Android يحول UTF-8 إلى ملف `text/plain` ويمر بمسار الملفات نفسه؛ لا endpoint نص مختلق.
5. المكتبة تدمج الملف والمستند بواسطة `file_id` وتتعامل مع cursor مستقل للقائمتين.
6. البحث Top-k داخل مساحة واحدة؛ النتائج مقتطفات مرتبطة بالمصدر، مع الصفحة والقسم عند توفرهما، بلا score ظاهر أو جواب مولد أو pagination وهمي.
7. رسالة الحذف توضح الحذف الناعم للملف والتطهير غير القابل للتراجع للمستندات والقطع والفهرس.
8. أضيف تحذير استبدال الاسم المطابق قبل الرفع مع الإفصاح أن الفحص best-effort ولا يمنع سباقاً متزامناً.
9. تظهر لقطة العقد ومصدرها داخل أدوات المراجعة، ولا تُقدّم على أنها عقد `master` مؤكد.

## سلطة العقد والقيود

حزمة API مصدرها `chore/public-file-links-closing@ff547ad8228741a532077b8eaf8fa2eb928be782` بتاريخ 2026-10-22، وليست دليلاً مؤكداً على `master` العامل. لذلك لا يبدأ التنفيذ المتأثر قبل رد موثق يؤكد:

- مفتاح/قدرة Data Search ومصدر صلاحيات العميل.
- أسماء صلاحيات قراءة/كتابة/حذف الملفات الدقيقة.
- أنواع MIME والأحجام وقبول `text/plain`.
- سلوك استعادة رابط رفع منتهٍ وسياسة المسودة وoffline cache.
- أن مسارات وحقول وحالات الملفات والمعرفة الموثقة منشورة على `master`.

لم يُجر أي تعديل على الباك إند أو التطبيق.
