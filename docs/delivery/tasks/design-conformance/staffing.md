# توزيع فريق معالجة مطابقة التصميم

المهمة: `design-conformance`  
المسار: `ui-redesign`  
خط أساس Git عند الاستلام: `2e57e8edc40c926804e6626ba507c861858504e9`

| المرحلة | الدور المطلوب | التعيين | الملكية |
|---|---|---|---|
| الاستلام والتنسيق | `company-director` | الجلسة الرئيسية | سجل دورة المهمة، قبول التسليمات، وحزم نقاط الاعتماد فقط |
| بنية الرحلات | `ux-designer` | متخصص `ui-ux-designer` المتاح في المضيف، يعمل بعقد `ux-designer` | `journeys-wireframes.md` |
| المرجع القابل للفحص | `ui-designer` | متخصص `ui-ux-designer` مستقل عن تسليم UX، يعمل بعقد `ui-designer` | `design-tokens.md` و`screen-inventory.json` |
| تنفيذ Compose | `compose-developer` | يُعيّن بعد اعتماد التصميم | ملفات UI ومواردها واختبارات screenshots فقط؛ لا ViewModels أو مستودعات أو عقود مصادقة |
| التحقق | `qa-engineer` | يُعيّن بعد التنفيذ | مصفوفة التحقق وأدلة البوابات؛ دون إصلاح صامت للمصدر |
| مطابقة التصميم | `design-qa-reviewer` | يجب أن يكون مستقلاً عن التنفيذ | سجل المطابقة المبني على لقطات المصدر الحالي؛ تبقى المرحلة محجوبة إن لم يتوفر مراجع مستقل |

## حدود ثابتة

- لا تعديل للباك إند أو مستودعه أو عقوده.
- الخروج محلي فقط؛ يبقى محول HTTP غير مستدعى.
- لا تعديل في ViewModels أو المستودعات أو عقود المصادقة الحالية.
- أي فرق ضروري عن المرجع يسجل كـ deviation على عنصر محدد ويحتاج اعتماد المالك قبل اعتباره مقبولاً.
- لا يبدأ تنفيذ Compose قبل اعتماد `screen-inventory.json` مع المرجع وبصماتهما.
