# توثيق API لمنصة AIZZAK

هذه الحزمة مستقلة عن مشروع AIZZAK ومبنية من عقد OpenAPI الرسمي الموجود في المشروع عند الالتزام:

- الفرع: chore/public-file-links-closing
- الالتزام: ff547ad8228741a532077b8eaf8fa2eb928be782
- إصدار العقد: 1.0.0
- OpenAPI: 3.1.0
- عدد المسارات: 58
- عدد العمليات: 77
- تاريخ إنشاء الحزمة: 2026-10-22

## محتويات الحزمة

- openapi.yaml: العقد الرسمي القابل للاستيراد في Postman وInsomnia وأدوات توليد SDK.
- index.html: توثيق ReDoc مرتب للقراءة والبحث، ويعمل مباشرةً دون خادم.
- swagger.html: واجهة Swagger UI للتجربة التفاعلية، وتعمل مباشرةً دون خادم.
- openapi.js وassets/: نسخة محلية للعارضين، حتى لا تعتمد الصفحات على الإنترنت أو على جلب YAML عبر file://.
- api-specification.md: المواصفة العربية التفصيلية، وتشمل SSE وWebSocket والأخطاء.
- QUICKSTART.md: دليل بدء سريع للمطورين.
- serve.ps1: خادم محلي بسيط لفتح التوثيق في المتصفح.

## العرض المحلي

افتح index.html أو swagger.html بالنقر المزدوج. لا تحتاج إلى تشغيل خادم، ولا تحتاج الصفحة إلى اتصال بالإنترنت.

ويمكن تشغيل خادم محلي اختياريًا من PowerShell داخل هذا المجلد:

من PowerShell داخل هذا المجلد:

~~~powershell
.\serve.ps1
~~~

ثم افتح أحد العنوانين:

- http://localhost:8088/index.html
- http://localhost:8088/swagger.html

ملفات HTML مصممة الآن للعمل مباشرةً وكذلك عبر الخادم المحلي.

## قواعد أساسية للعميل

- أغلب المسارات تستخدم الأساس /api/v1.
- المصادقة عبر Firebase ID Token بصيغة Bearer JWT.
- مساحة العمل مشتقة من الهوية ولا يرسل العميل workspace_id لتحديد المستأجر.
- الأخطاء تستخدم RFC 9457 والنوع application/problem+json.
- القوائم تستخدم ترقيمًا بالمؤشر cursor وتُغلّف داخل data وmeta.
- أرسل X-Correlation-Id اختياريًا للتتبع؛ الخادم يعيده أو ينشئه.
- أرسل Idempotency-Key في العمليات المدعومة لتأمين إعادة المحاولة.
- WebSocket التفاعلي هو GET /api/v1/ws، وتفاصيله في api-specification.md.

## الاستيراد في Postman

اختر Import ثم ارفع openapi.yaml. سيُنشئ Postman مجموعة الطلبات والنماذج من العقد مباشرة.

## ملاحظة أمنية

لا تضع رموز Firebase أو مفاتيح المزودين داخل ملفات التوثيق. استخدم متغيرات بيئة محلية عند التجربة.
